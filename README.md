# ✈️ WanderWise

WanderWise is a simple beginner Python project that lets users create a small travel plan based on their destination, trip duration, budget, and activities.

I built this project while learning and practicing my **Python fundamentals**. It focuses on using basic Python concepts rather than advanced features.

## 🌍 Features

* Choose a travel destination
* 📅 Select trip duration
* 💰 Choose a budget range
* 🎯 Select activities
* 🛒 Create a simple activity cart
* 💵 Calculate the total activity cost
* ✨ Get a **traveling style** using emojis based on the activities you choose
* ✅ Confirm your trip

### ✨ Traveling Style

One of the small features I added is a fun **traveling style** system.

Each activity has its own emoji, and the emojis are combined based on the activities selected by the user.

For example:

`🏯🗼🏖️`

So instead of just getting a list of activities, the user gets a little emoji representation of their travel style!
